# Além da Web — Portfólio

Portfólio responsivo da Além da Web, desenvolvido com Next.js, React, TypeScript e CSS.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Produção

```bash
npm run build
npm start
```

O projeto está preparado para implantação na Vercel.

## Notas

- A hero utiliza arte abstrata em CSS e não exibe screenshots de clientes.
- A demonstração do projeto Nádia Kroetz Odontologia aparece somente na seção Projetos.
- O contato direciona ao Instagram até que um número de WhatsApp seja fornecido.
- Não foram adicionadas métricas comerciais, depoimentos ou resultados não verificados.
